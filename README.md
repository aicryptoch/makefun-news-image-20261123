THE COMPLETE RECORD — a one-image front page summing up Monday 23 November 2026. Forty stories from seven regions, every one from that single day: 13 numbered main cards led by the Kyiv story (fourteen missing after a Russian drone strike, Zelenskiy says), a day-in-numbers strip, a dotted world map with numbered pins, 27 further numbered briefs, and a date-check box naming the older stories that were checked and left out. Contested claims are framed as claims on the cards themselves.

## Run it

```sh
python3 main.py
```

The program copies `entry.png` byte-for-byte to `$MAKEFUN_OUTPUT_DIR` (default `/output`), verifying size and SHA-256 on the way.
